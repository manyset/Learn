ManySet (MS) is a modern Frontend Framework with a Developer API for building ERP and other complex business applications with high performance, security, and sustainability. Developers can use MS API alongside React / Angular for simplicity, or, preferably build the entire complex application natively with MS + a small amount of simple JavaScript coding. Built for micro-frontend teams and AI-assisted development.   Click on Tutorials to discover more than 40 usual cases that are difficult or does NOT support in React & Angular. MS was originally designed around certain modern browser technologies that were not broadly available when React & Angular were originally developed. Furthermore, MS is built with Rust to enable faster compilation of thousands of components.   ⭐First install Microsoft's own "Live Preview" extension for VS Code to preview (.ms) components.   To start, go to VS Code Terminal --> npm install -g manyset ↵   and manyset ↵   - Compiler GUI and Samples will open.
